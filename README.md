# CUSTOM STUDIO®

A bilingual (English / Arabic) responsive website for an independent creative studio based in Jordan.

## Included
- Responsive studio landing page: services, concept portfolio, process, about, FAQ and contact.
- English/Arabic language switcher with RTL layout and local language preference.
- Contact form prepares a message locally, attempts clipboard copy, then opens Instagram. It does not send form data to a server.
- Privacy, Cookie, Terms of Use, Service Terms, Disclaimer and 404 pages.
- Responsive navigation, keyboard focus, reduced-motion support and semantic page sections.

## Run locally
Open `index.html` in a modern browser. No build step or package manager is needed.

## Publish with GitHub Pages
Go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Wait for GitHub to show the published URL in Settings → Pages.

## Before launch
- Portfolio visuals are self-initiated concepts, not client work.
- Contact has no backend; visitors copy a prepared message and send it through Instagram.
- Review policy text against actual business practices and applicable local law.
- No analytics or tracking scripts are included.
- Add a custom domain/canonical URL after configuring a domain.
